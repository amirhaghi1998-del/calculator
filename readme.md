# Simple Calculator
#Live Demo
click the link below to see the live calculator:
[Live Demo](https://amirhaghi1998-del.github.io/calculator/)
This project is a simple calculator built with HTML, CSS, and JavaScript.

## Features
- Four basic operations (addition, subtraction, multiplication, division)
- Support for decimal numbers
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)

## How to Run
Open the index.html file.
